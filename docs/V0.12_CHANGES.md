Source: `GabayNegosyo_v0.11_Sprint1_Feature_Audit.md`, based on the Complete Improvement & Feature Validation Plan. Scope: P0 functional bugs that did not need a client decision. Nothing here is a visual redesign.

## Behaviour notes

- Annual completion stores the cycle's due date as `YYYY-MM-DDT12:00:00Z` so the calendar day survives any timezone. The old code stored local-midnight ISO strings, which shifted Jan 1 into the previous UTC year. Legacy rows still read correctly (only the year is used).
- "Existing" progress rows from v0.11 for annual items carry their old due date; they count as that cycle's completion.
- Reminders are disabled for requirements with no fixed date (nothing to count back from).
- An email-confirmation signup opens the confirmation link in a new tab; the guest preview does not carry across tabs, so that person re-runs the wizard. Known limitation of using `sessionStorage`.
